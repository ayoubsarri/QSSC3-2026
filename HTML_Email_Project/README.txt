QSSC3 Summer Camp 2026 - HTML Email Template Project Folder
============================================================

This folder contains a rebuilt responsive Arabic HTML email invitation.
The design uses a clean email-card layout with exact logo image files,
live Arabic text, cleaned transparent icons, and a clickable registration
button.

FILES INCLUDED:

1. email_template_offline.html
   - Uses local image paths under ./images/.
   - Open this file locally or through a local preview server.

2. email_template_hosted.html
   - Uses hosted image URLs under https://qssc3-d300f.web.app/images/.
   - Use this version after deploying the updated images folder.

3. images/
   - Contains the campus hero crop, exact logo files, and cleaned icon files.
   - The cleaned icons use *_clean.png filenames.

The visible website text has been removed. The registration button links to:
https://qssc3-d300f.web.app
