Two ways:

1. Vite (recommended — fast, modern)

bash
npm create vite@latest my-app -- --template react

npm install
npm run dev

2. Create React App (classic)

bash
npx create-react-app my-app
cd my-app
npm start

After npm run dev, your app is at http://localhost:5173 and hot-reloads on every save.
